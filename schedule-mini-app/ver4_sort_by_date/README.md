# ver4_sort_by_date

スケジュール管理アプリ（ミニ）のVer.4。Ver.3（追加・一覧表示・編集・削除・保存/読み込み）に、日付順への並び替えを追加した。

## Ver.3からの変更点

- メニューに `5: 日付順に並び替え` を追加した。
- 並び替えは年→月→日の順で比較する昇順ソートで、基本情報技術者試験アルゴリズムシリーズのバブルソートと同じ考え方を `Schedule` 構造体の配列に適用したもの。
- 並び替え後は自動的に一覧を表示する。
- 同じ日付の予定同士は、並び替え前の順序（登録順）を保ったまま並ぶ（安定ソート）。

## プログラムについて

対応している操作は次の6つ。

- `1`：予定を追加する
- `2`：登録済みの予定を一覧表示する
- `3`：予定を編集する
- `4`：予定を削除する
- `5`：登録済みの予定を日付順に並び替える
- `0`：終了する（このタイミングで自動保存される）

## 使い方

```bash
gcc -Wall -Wextra -o schedule schedule.c
./schedule
```

日付がバラバラの順で登録されていても、`5` を選ぶと日付順に並び替えられる。

```
番号を入力してください: 5
日付順に並び替えました。

--- 予定一覧 ---
1: 2025-12-31  Z予定
2: 2026-08-01  A予定
3: 2026-08-20  B予定
4: 2026-08-20  B2予定(同日)
```

登録されている予定が0件または1件のときは、並び替える必要が無いため「並び替えの対象となる予定がありません。」と表示するだけで終了する。

## 注意事項

- 並び替えは配列の中身そのものを並び替える（表示だけを一時的に並び替えているわけではない）。そのため並び替え後にファイルへ保存すると、`schedules.txt` の中身も日付順になる。
- 日付の妥当性チェックはVer.1〜Ver.3と同じ範囲チェック（月1〜12、日1〜31）のみで、2月31日のような実在しない日付までは弾いていない。そのため、そうした日付が登録された場合も、値としてはそのまま比較・並び替えの対象になる。
