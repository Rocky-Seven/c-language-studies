# ver3_edit_and_delete

スケジュール管理アプリ（ミニ）のVer.3。
Ver.2（追加・一覧表示・ファイル保存/読み込み）に、予定の編集・削除を追加した。

## Ver.2からの変更点

- メニューに `3: 予定を編集`・`4: 予定を削除` を追加した。
- 編集・削除は、一覧表示の番号（`1`始まり）で対象を指定する。
- 追加・編集で使う「年月日と予定の入力」を `read_schedule_input` 関数に共通化した。
- 番号を選ぶ処理（一覧表示→番号入力→検証）を `select_schedule_index` 関数に共通化し、編集・削除の両方から使っている。
- ファイルへの保存・読み込みはVer.2と同じ仕組みのまま（終了時に自動保存、起動時に自動読み込み）。

## プログラムについて

対応している操作は次の5つ。

- `1`：予定を追加する
- `2`：登録済みの予定を一覧表示する
- `3`：予定を編集する
- `4`：予定を削除する
- `0`：終了する（このタイミングで自動保存される）

## 使い方

```bash
gcc -Wall -Wextra -o schedule schedule.c
./schedule
```

### 3: 編集する場合

まず現在の一覧が表示され、続けて編集したい予定の番号を入力する。その後は追加のときと同じく、年月日→予定の内容の順に入力する（値の一部だけを変更することはできず、両方とも入力し直す仕様）。

```
--- 予定一覧 ---
1: 2026-08-01  A予定
2: 2026-08-02  B予定
3: 2026-08-03  C予定
編集する予定の番号を入力してください: 2
年月日を入力してください（例: 2026 8 1 または 20260801）: 2026 8 20
予定を入力してください: B予定(更新)
予定を更新しました。
```

### 4: 削除する場合

同様に一覧が表示され、削除したい予定の番号を入力する。削除すると、それより後ろの予定の番号は1つずつ繰り上がる。

```
--- 予定一覧 ---
1: 2026-08-01  A予定
2: 2026-08-20  B予定(更新)
3: 2026-08-03  C予定
削除する予定の番号を入力してください: 1
予定を削除しました。
```

## 入力に関する注意事項

- 年月日の入力形式（半角スペース区切り・8桁連続表記のみ対応）、予定を空にできない仕様はVer.1・Ver.2と同じ。
- 予定が1件も登録されていない状態で編集・削除を選ぶと、「登録されている予定はありません。」と表示され、番号の入力を求めずに処理を中止する。
- 存在しない番号（`0`、登録件数を超える番号など）や、数値以外の入力の場合は「該当する予定がありません。」または「正しい番号を入力してください。」と表示し、何も変更せずに処理を中止する。
