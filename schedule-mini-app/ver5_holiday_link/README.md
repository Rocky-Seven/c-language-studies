# ver5_holiday_link

スケジュール管理アプリ（ミニ）のVer.5。Ver.4（追加・一覧表示・編集・削除・保存/読み込み・日付順ソート）に、祝日データとの連携を追加した。

## Ver.4からの変更点

- 起動時に `holidays.csv` を読み込む（無ければ「祝日連携なし」で続行する）。
- 予定の追加・編集時、入力した日付が祝日と一致する場合、「この日は祝日です（○○）。」と参考情報を表示する（入力を止めるものではない）。
- 一覧表示で、祝日と重なる予定には `[祝: 祝日名]` を付けて表示する。

## holidays.csvについて

「マルチ言語（C言語、Go言語、Rust、Kotlin）で祝日対応のカレンダーをつくろう！」企画（`multi-pg-lang-calendar`）で使っているものと同じ形式を想定している。

- 1行目はヘッダー行（読み飛ばす）
- 2行目以降は `年/月/日,祝日名` の形式（例: `2026/5/3,憲法記念日`）
- 内閣府の祝日CSV（`https://www8.cao.go.jp/chosei/shukujitsu/syukujitsu.csv`）をUTF-8変換したものをそのまま使える

このリポジトリには、動作確認用として固定日の祝日のみを集めた小さなサンプル（`holidays.csv`）を同梱している。実際に使う場合は、`multi-pg-lang-calendar` 側で用意した内閣府CSV（UTF-8変換済み）をこのフォルダにコピーすることを想定している。

`holidays.csv` が無い状態で起動した場合は、エラーにはせず「祝日データ(holidays.csv)が見つかりませんでした。祝日連携なしで続行します。」と表示し、祝日情報を使わない通常のVer.4相当の動作になる。

## プログラムについて

対応している操作（メニュー）はVer.4と同じ6つ。

- `1`：予定を追加する
- `2`：登録済みの予定を一覧表示する
- `3`：予定を編集する
- `4`：予定を削除する
- `5`：登録済みの予定を日付順に並び替える
- `0`：終了する（このタイミングで自動保存される）

## 使い方

```bash
gcc -Wall -Wextra -o schedule schedule.c
./schedule
```

祝日と重なる日付で予定を追加すると、追加の途中で祝日名が表示される。

```
番号を入力してください: 1
年月日を入力してください（例: 2026 8 1 または 20260801）: 2026 5 3
この日は祝日です（憲法記念日）。
予定を入力してください: 家族で外出
予定を追加しました。
```

一覧表示では、該当する予定の末尾に祝日名が付く。

```
--- 予定一覧 ---
1: 2026-05-03  家族で外出  [祝: 憲法記念日]
```

## 入力・データに関する注意事項

- 年月日の入力形式、予定を空にできない仕様など、Ver.1〜Ver.4の内容はそのまま引き継いでいる。
- `holidays.csv` の行のうち、カンマが無い行や、月日が範囲外（1〜12、1〜31）の行は読み込み対象から除外する（`schedules.txt` の読み込みと同じ考え方）。ただしholidays.csv側は除外件数を表示していない点はVer.2の予定データと異なる。
- 祝日と重なっていても、予定の追加・編集自体を止めることはない。あくまで参考情報としての表示にとどめている。
